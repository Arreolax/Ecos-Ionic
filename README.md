# 🌿 Ecos - Diario Personal, Notas y Álbum Fotográfico

¡Bienvenido a **Ecos**! Tu espacio personal y privado diseñado para guardar tus pensamientos, recuerdos y tareas del día a día. Hemos creado esta aplicación para que sea muy fácil de usar y tengas tu propio diario, bloc de notas y álbum de fotos, todo en la palma de tu mano.

---

## ✨ Lo que puedes hacer en Ecos

### 🔒 Tu Espacio Seguro
Tus recuerdos son solo tuyos. Ecos te permite crear tu propia cuenta con usuario y contraseña. Todo tu contenido está protegido y guardado de forma segura para que solo tú puedas verlo.

### 🏠 Pantalla de Inicio
Al entrar, te recibimos con un resumen de tu actividad. Desde aquí tienes acceso súper rápido a la cámara para no perderte ningún momento especial, además de un vistazo rápido a tus fotografías más recientes.

### 📸 Cámara y Álbum de Fotos
- **Captura el momento:** Toma fotos directamente desde la aplicación o elige tus favoritas desde la galería de tu teléfono.
- **Dales un significado:** A cada foto puedes añadirle un título y escribir lo que estabas pensando o sintiendo en ese momento.
- **Tu Galería:** Revisa todas tus fotos organizadas en un bonito álbum. Si quieres recordar una memoria en detalle, simplemente toca la foto para leer la nota que le dejaste.

### 📝 Notas y Diario
Un espacio flexible para que no olvides ninguna idea:
- **Encuentra todo rápido:** Usa el buscador para encontrar cualquier apunte al instante.
- **Organízate a tu manera:** Clasifica tus notas por categorías como *Personal*, *Ideas*, *Trabajo*, *Importante* o *Diario*.
- **Ponles color:** Cambia el color de tus notas para identificarlas de un solo vistazo.
- **Lo más importante, primero:** Fija tus notas favoritas o urgentes con un "pin" para que siempre aparezcan hasta arriba.

### 👤 Tu Perfil
Revisa y actualiza tu información personal fácilmente. Puedes modificar tus datos de contacto, cambiar tu contraseña de forma segura o consultar cuántas memorias y apuntes has creado desde que empezaste a usar Ecos.
